# Portfolio de Marcos Gómez

Portfolio web bilingüe de Marcos Gómez (`@maarquezz17`), estudiante de DAM interesado en sistemas, desarrollo de software y diseño de interfaces para videojuegos.

## Ejecutar en local

Abre `index.html` en un navegador o sirve el directorio con una extensión como Live Server.

## Funciones

- Tema claro/oscuro e idioma español/inglés, con preferencias guardadas en el navegador.
- Filtros por áreas de enfoque y categorías de proyectos.
- Terminal interactiva con los comandos `help`, `skills`, `projects`, `contact`, `cat about.txt`, `clear` y `sudo`.
- Vista de impresión para guardar el portfolio como PDF desde el diálogo del navegador.
- Diseño adaptable, animaciones de entrada y compatibilidad con la preferencia de movimiento reducido.

## Estructura

- `index.html`: contenido y estructura del portfolio.
- `css/portfolio.css`: estilos, temas, diseño adaptable y estilos de impresión.
- `css/styles.css`: base de Bootstrap incluida en la plantilla original.
- `js/scripts.js`: traducciones, preferencias, filtros, terminal y microinteracciones.
